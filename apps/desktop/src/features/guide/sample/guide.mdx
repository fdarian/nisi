## Overview

Guides are now written to `.nisi/guide` and read in the Guide tab, with test results recorded by a script instead of typed in.

<Sequence title="Getting a check result into the guide" lanes={["Agent", "Sidecar", "Guide tab"]}>
	<Before>
		<Step lane="Agent" area="authoring" span={4}>runs tests, types the result</Step>
		<Wait lane="Sidecar" span={4} />
		<Step lane="Sidecar" area="bundle" span={2}>bundles guide.mdx</Step>
		<Wait lane="Guide tab" span={6} />
		<Step lane="Guide tab" area="app" span={2}>prose, unverifiable</Step>
		<Event lane="Agent" at={4} />
	</Before>
	<After caption="The result is a record with the commit it ran at, so the tab can say when it's stale.">
		<Step lane="Agent" area="authoring" span={3}>check.ts runs it</Step>
		<Wait lane="Sidecar" span={3} />
		<Step lane="Sidecar" area="bundle" span={2}>reads the record</Step>
		<Wait lane="Guide tab" span={5} />
		<Step lane="Guide tab" area="app" span={3}>Checks row, stale or current</Step>
		<Event lane="Agent" at={3} area="authoring" />
	</After>
</Sequence>

<Areas>
	<Area id="authoring" title="Authoring" subtitle="skill · scripts" paths={[".claude/skills/**"]}>

	</Area>
</Areas>

## How it works

<Note label="Bundled in the sidecar, evaluated in the app">
	The bundle externalises React and the kit, so a guide never ships a second
	copy of either. See <Ref path="apps/desktop/sidecar/guide/build.ts" lines="70-95" />
	and <Ref path="apps/desktop/src/features/guide/evaluate.ts" lines="36-60" />.
</Note>

<Note label="Plain backticked paths link too">
	`apps/desktop/sidecar/guide/build.ts:70-95` and `apps/desktop/src/features/guide/evaluate.ts`
	are in the diff, so they open the pane. `README.md` isn't, so it stays code.
</Note>
