# Guides: write one in .nisi/guide, read it in the Guide tab

- The sidecar bundles `guide.mdx`; the app evaluates it against its own React and the kit.
- Clicking a file reference opens that file's diff beside the guide.
- Test and lint results are recorded by a script, not typed in.

	and <Ref path="apps/desktop/src/features/guide/evaluate.ts" lines="36-60" />.
