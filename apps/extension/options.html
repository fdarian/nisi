nisi

Hands a GitHub pull request page off to the nisi app when you arrive at it directly — a link from Slack, a typed or pasted URL, a bookmark. Clicking around inside GitHub itself never triggers it.

The hand-off lands on an interstitial page in the same tab, which fires the deep link and stays open. Chrome gives no reliable way to tell whether its "open nisi?" confirmation prompt is still pending, so the tab is never closed automatically — the interstitial offers a retry button and a link back to the pull request on GitHub instead.
