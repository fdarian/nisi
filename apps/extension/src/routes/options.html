nisi

Hands a GitHub pull request page off to the nisi app when you arrive at it directly — a link from Slack, a typed or pasted URL, a bookmark. Clicking around inside GitHub itself never triggers it.

The hand-off lands on an interstitial page in the same tab, which fires the deep link. It stays open the first time, so you can confirm nisi actually opened before deciding whether it should close the tab automatically on every hand-off after that.
